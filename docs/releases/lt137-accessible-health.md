legacy action a distinct ID, and share the existing width/margin styling through
a class. The final selector retains enough specificity to override Semantic UI's
button margin. The legacy table remains hidden. Ordinary section editing is available
when optional Remedy is disabled.

including a peer that continually sends partial response bytes. Deadline failures
return fixed unavailable feedback with all effective capabilities false; no raw
error, credential or internal address is returned. Normal responses retain the
existing capability policy. Page-action timeouts, authorization, stored targets,
write/no-op/uncertain outcomes, pending claims and explicit recovery are unchanged.
